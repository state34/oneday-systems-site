# Fonts

Self-hosted Montserrat for the weights and style the pages requested: normal 400, 500, 600, 700, and 800, latin subset. The file below is the unmodified woff2 those faces share. It was not re-subset or re-encoded. `OFL.txt` is the unmodified SIL Open Font License that accompanies the family.

## montserrat-latin.woff2

- Family: Montserrat
- Style: normal
- Weights: 400, 500, 600, 700, 800
- Subset: latin
- Format: woff2 variable font, `wght` axis 100–900, version 9.000. The CSS2 response for these five weights points every latin face at this single file.
- sha256: `06b16db7a969135d48d38c49183be7fb88d4452e2a3011957c7851941f4e4879`
- Source URL: `https://fonts.gstatic.com/s/montserrat/v31/JTUSjIg1_i6t8kCHKm459Wlhyw.woff2`

Retrieved from the latin block of the CSS2 stylesheet for `family=Montserrat:wght@400;500;600;700;800&display=swap`. The same URL is used for each of those weights.

Upstream design repository recorded by the Google Fonts Montserrat package: <https://github.com/JulietaUla/Montserrat> at commit `cc8daf2e7085006b9c112542fc82b58afc13521d`.
